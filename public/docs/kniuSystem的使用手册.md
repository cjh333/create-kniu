## 1. 三分钟上手

### 1.1 打开与登录

- **前台**（读者看的网站）：打开你的网站首页。
- **后台**（你写文章、管评论的地方）：在网站首页右上角点「登录」，或直接打开登录页。
- 登录要填三样：**账号**、**密码**、**图形验证码**。
  - 验证码是图上的算式结果，例如图上写 `3 + 5 = ?`，就填 `8`。
  - 看不清？点一下验证码图片，会换一张。

还没有账号？在登录页点「注册」，用邮箱验证码就能自助注册；忘记密码也可以在登录页点「忘记密码？」，用注册邮箱收验证码后自行重置（详见第 9 章）。

### 1.2 后台长什么样

| 位置 | 有什么 | 用途 |
| --- | --- | --- |
| 左侧菜单 | 控制台 / 网站信息 / 关于我 / 每日一句 / 文章管理 / 账号管理 / 评论管理 / 回复管理 / 数据库管理 | 点一下切换功能，你只会有自己用得上的那几项 |
| 顶部左侧 | 面包屑（如「工作台 / 文章管理」） | 显示你当前在哪一页 |
| 顶部右侧 | 「前端首页」、铃铛、刷新图标 | 新窗口打开网站 / 查看有没有新回复 / 重新载入当前列表 |
| 中间 | 当前功能的列表和表单 | 你主要在这里干活 |
| 左下角 | 「帮助」、「退出登录」、你的头像和名字 | 「帮助」打开的就是本手册 |

> 「控制台」是进入后台的第一页，显示你的账号、所属角色和服务器时间等信息，平时不用管它。

### 1.3 每个人看到的不完全一样

系统按账号分配功能：**你只能看到与你的工作相关的菜单，也只会看到属于自己的内容**——文章列表里只有你写的文章，评论列表里只有你发的评论。

- 「网站信息」「账号管理」「数据库管理」属于管理类功能，只有管理员（或超级管理员）能看到。
- 如果你发现自己的菜单比别人少，这是正常的权限分配，不影响你写文章和管评论；确实需要更多功能时，联系网站管理员。

### 1.4 用完记得退出

左下角点「退出登录」。公共电脑上尤其要注意。

## 2. 发表一篇文章

### 2.1 五步发一篇

1. 左侧菜单点「**文章管理**」。
2. 右上角点「**添加**」按钮。
3. 在弹出的窗口里填写各项内容（每个字段的作用见 2.2）。
4. 在「正文」区域撰写文章主体（写法见第 3 章）。
5. 点右下角「**保 存**」。窗口会自动关闭，新文章出现在列表第一行。

### 2.2 每个字段填什么

| 字段 | 怎么填 | 会显示在哪 |
| --- | --- | --- |
| **排序** | 数字。数字越小越靠前；不确定就填 0 | 只影响列表顺序，前台不显示 |
| **标题** | 文章标题 | 前台列表和文章页的主标题 |
| **副标题** | 一句话补充说明，没内容就留空 | 文章标题下方 |
| **摘要** | 一到两句话的内容简介 | 前台首页列表里的简介 |
| **链接** | 一般是外部链接，没有就留空 | 视模板而定 |
| **发布时间** | 前台显示的发布时间，默认今天，点一下可改 | 文章页「发布于」 |
| **正文** | 文章主体内容 | 文章页正文区 |
| **封面** | 点「选择图片」上传，图片文件、不超过 5MB | 列表里的封面小图 |
| **显示** | 开关。打开=前台能看到；关闭=只有后台能看到 | 控制前台是否展示 |
| **推荐** | 开关（仅管理员可见）。打开=文章有资格进入首页「推荐好文」位 | 首页推荐位 |

### 2.3 修改、删除与排序

- **修改**：列表右侧点「修改」，改完点「保存」。
- **删除**：列表右侧点「删除」。⚠️ 删除后无法恢复，删前确认清楚。
- **改排序**：列表里「排序」列的数字可以直接点开修改，回车生效。
- **临时下架**：列表里「显示」列的开关，关掉前台立刻看不到，内容不会丢。
- **找文章**：右上角搜索框输入标题关键词，回车或点放大镜。
- **翻页**：列表底部可切换页码、每页条数。

> 你只能看到和操作自己写的文章。别人的文章不会出现在你的列表里。

### 2.4 写完怎么检查效果

点顶部「**前端首页**」（会在新标签页打开网站）→ 在首页找到你的文章 → 点进去看排版。

**看不到文章？** 先回列表看看「显示」开关是不是关着的。

## 3. 正文编辑器怎么用

### 3.1 基本操作

点进「正文」框直接打字即可。工具栏上的按钮，作用对象是**你选中的文字**，或者**光标所在的那一段**。

编辑器有两种形态，由字段类型自动决定，不需要你手动切换：

- **富文本模式**（文章正文等长文本字段）：所见即所得，像 Word 一样直接排版。
- **源码模式**（代码类字段）：以纯文本语法书写内容，适合代码、配置类文字；一般只在数据库管理编辑特定字段时出现。

### 3.2 富文本工具栏按分组说明

| 分组 | 按钮 | 作用 |
| --- | --- | --- |
| 历史 | 撤销 / 重做 | 撤销上一步、恢复被撤销的操作 |
| 视图 | 打印 / 源码模式 / 最大化 | 打印正文 / 查看网页代码 / 放大编辑区，只影响查看方式，不改内容 |
| 字体样式 | 加粗 / 斜体 / 下划线 / 删除线 / 下标 / 上标 | 给选中文字加样式 |
| 行距 | 「行距 ▾」 | 1.0 ~ 3.0 六档，调整光标所在段落的行间距 |
| 清除格式 | 清除格式 | 只去掉选中文字的颜色、字号等，段落、链接、图片都保留 |
| 清理 HTML | 清理HTML | ⚠️ 把**整篇**文章变成纯文字：图片、链接、表格、列表结构全部丢失，且无法撤销，慎用 |
| 对齐 | 左对齐 / 居中 / 右对齐 / 两端对齐 | 调整光标所在段落 |
| 列表 | 有序列表 / 无序列表 | 做编号或圆点列表 |
| 缩进 | 增加缩进 / 减少缩进 | 让段落往右或往左缩 |
| 块级 | 「标题 ▾」/ 段落 / 引用 / 代码块 | 「标题 ▾」里可选 H1 ~ H6；点了标题想改回普通文字就选「段落」 |
| 插入 | 表格 / 分割线 / 表情 / 图片 / 音视频 / 链接 / 取消链接 / 行内代码 | 插入各种元素 |
| 字体 | 「字体 ▾」「字号 ▾」「字距 ▾」「文字颜色 ▾」「文字背景 ▾」 | 以弹出小面板的方式选择 |
| 其它 | 全选 | 选中编辑器里的全部内容 |

### 3.3 常用操作怎么做

- **做小标题**：选中文字 →「标题 ▾」选 H2 / H3。文章大标题由「标题」字段负责，正文里从小标题开始。
- **插入图片**：点图片按钮 → 选择本地图片上传，或填写图片地址。
- **插入视频**：点音视频按钮 → 上传或用视频地址。
- **加链接**：先选中要变成链接的文字 → 点链接按钮 → 填网址。想取消链接，选中后点「取消链接」。
- **插入表格**：点表格按钮，设定行列数；插入后可在单元格里继续输入。
- **从别处复制内容**：粘贴后先点「清除格式」，再自己重新排版，避免带入外部字体和颜色。
- **写错了**：`Ctrl + Z` 撤销（注意：用了「清理HTML」之后就撤不回来了）。

### 3.4 小提示

- 字体、字号、颜色、标题、行距这些下拉，都会**记住你打开前的选中内容**，选完继续作用在那段文字上，不用重新选。
- 换行请直接按回车新起一段，不要用空格硬推位置。
- 表格、图片这类内容，建议在「最大化」状态下编辑，视野更宽。

## 4. 我的评论

### 4.1 评论是怎么来的

你在前台文章页底部的评论区留言（需要先登录前台账号），提交后会看到提示「**审核通过后将展示**」。也就是说，评论提交后是**待审核**状态，等管理员审核通过，其他读者才能看到。

### 4.2 查看自己的评论

1. 左侧菜单点「**评论管理**」。
2. 列表里只显示**你自己发出的评论**，以及每条评论的状态。

**列表各列含义**

| 列 | 含义 |
| --- | --- |
| 账号 / 昵称 | 评论人（就是你） |
| 评论内容 | 你写了什么 |
| 所属文章标题 | 这条评论写在哪篇文章下 |
| 点赞 | 这条评论被其他读者点赞的次数 |
| 状态 | **待审核**（还没展示）/ **已通过**（读者可见） |
| 创建时间 | 评论提交的时间 |

### 4.3 筛选与查找

- 列表上方「审核」可以切成「**全部**」「**待审核**」「**已通过**」，用来快速看哪些评论还没被放行。
- 右上角搜索框可按**评论内容**查找，回车或点放大镜即可。

### 4.4 删除自己的评论

- 列表右侧点「**删除**」即可删掉自己发的评论。
- ⚠️ 如果你删掉的是一条**顶层评论**，它下面别人对它的回复也会一起被删除，并且**删除无法撤销**。

> 如果发现自己的评论一直停在「待审核」，可以联系管理员处理；系统里评论是否需要审核由管理员统一设置。

## 5. 我的回复与消息提醒

### 5.1 回复管理是干什么的

「**回复管理**」列出的是**你自己发出的回复**（你在某条评论下面的回应）。

- 查看：每条回复的所属评论、内容、状态（待审核 / 已通过）、时间。
- 筛选：上方「审核」可切「全部 / 待审核 / 已通过」，和评论管理一样。
- 删除：右侧点「删除」，⚠️ 同样无法撤销。

### 5.2 别人回复了我会提醒

顶部右侧的**铃铛**就是提醒：

- 有未读的回复消息时，铃铛会变成「未读消息」的样子（带小红点）。
- 点一下铃铛 → 自动跳到「回复管理」，同时把小圆点清掉（表示已读）。
- 图标没有变化时，说明当前没有未读消息。

### 5.3 在前台参与回复

在文章页的评论区，每条评论下方都有「回复」按钮，点一下就能针对那条评论说话。你发出的回复同样需要审核通过后才会公开显示。

## 6. 关于我

- 入口：左侧菜单「**关于我**」。
- 三个部分：
  - **头像**：点「选择头像」上传图片（jpg / png / gif）。
  - **简述**：一句话介绍，显示在前台首页右侧的个人卡片上。
  - **关于我**：正文内容，可用第 3 章的编辑器排版。
- 填完点「提 交」。
- 效果：前台「关于我」页面展示你写的正文；首页右侧显示头像和简述。
- 你的「关于我」是你自己的，和别人互不影响。

## 7. 网站信息（管理员）

入口：左侧菜单「**网站信息**」。这里维护整站对外的展示信息，改完点「保存」立即对前台生效。

| 字段 | 用在哪 |
| --- | --- |
| 网站名称 | 浏览器标题、站点标识 |
| 网站域名 | 站点对外链接 |
| logo | 前台导航、后台侧栏顶部的品牌图 |
| description / keywords / author | 搜索引擎读取的页面描述、关键词与作者 |
| copyright | 页脚版权文字 |
| icp | 页脚备案号 |
| email | 对外联系邮箱 |

> 「显示」类开关与开关颜色约定与全站一致：右侧（绿色）= 开，左侧（红色）= 关。

## 8. 每日一句（管理员）

入口：左侧菜单「**每日一句**」。前台首页顶部每天展示一句话，由这里维护：

- **添加**：点「添加」，填写日期、中文句子、英文句子，保存即可。
- **修改 / 删除**：在列表中操作，删除无法恢复。
- 同一天只展示一条；某天没有记录时前台会留空或回退展示。

## 9. 我的账号

入口：左侧菜单「**账号管理**」。

### 9.1 你能看到什么

列表里只会出现**你自己的那一行**，可以看到：

| 列 | 含义 |
| --- | --- |
| 账号 | 你登录用的账号名 |
| 昵称 | 前台显示的名字 |
| 角色 | 你的账号类型 |
| 创建时间 | 账号创建的时间 |

### 9.2 修改昵称

- 在你那一行点「修改昵称」，填写新昵称保存即可。
- 昵称**一年只能改一次**，从上次修改时间起算；改前想清楚。
- 前台如有重名会提示，换一个再试。

### 9.3 修改密码

1. 在你那一行右侧点「**修改密码**」。
2. 填写**原密码**和**新密码**（要输两遍确认）。
3. 保存成功后系统会**自动退出登录**（其他已登录的设备也会一并退出），请用新密码重新登录。

> **密码要求**：8 位以上，并且同时包含**大写字母、小写字母、数字、特殊字符**（例如 `Abc12345!`）。不符合规则会提示密码不合格。

### 9.4 忘记密码怎么办

不用找人帮忙：在登录页点「**忘记密码？**」，按「账号 + 注册邮箱」定位，用邮箱收验证码，就能自己设置新密码。

## 10. 数据库管理（超级管理员）

这一整块只对**超级管理员**开放，普通账号不会看到入口。它让你在后台直接查看和维护网站数据库，不用另装数据库工具。

入口：左侧菜单「**数据库管理**」。四层页面逐级进入，随时可用面包屑或侧栏返回上一层。

### 10.1 连接管理

- 展示当前可用的数据库连接，可**新增 / 修改 / 删除 / 测试连接**。
- 「测试」通过才算有效连接；删除连接前请确认没有业务依赖。

### 10.2 数据库列表

- 展示所选连接下的所有数据库，支持**建库 / 导入 / 执行 SQL**。
- 「执行 SQL」窗口直接输入语句运行，结果以文本形式回显；⚠️ 写操作（删库、删表、改数据）不可恢复，执行前务必确认目标库。

### 10.3 数据表列表

- 点某个数据库进入，展示其中的表，支持**建表 / 导出**。
- 建表时按向导填写字段名、类型、长度、索引即可；导出得到建表语句。

### 10.4 表数据

- 点某张表进入，可对该表的数据行**增删改查**：
  - **新增 / 编辑**：弹窗内按字段填写。日期时间字段会出现日期选择器；长文本字段出现富文本编辑器（用法同第 3 章）；代码类字段以源码模式编辑。
  - **删除**：行内删除，⚠️ 无法恢复。
  - **搜索 / 排序**：按列排序、按关键字筛选。
- ⚠️ 数据库管理直接作用于真实数据，操作前建议先用「执行 SQL」里的查询语句确认影响范围。

## 11. 前台（读者看到的样子）

### 11.1 首页

- **每日一句**：顶部显示当天的中文和英文句子，并标注日期。
- **搜索框**：按文章标题搜索。
- **文章列表**：每条显示标题、摘要、发布人、发布时间、浏览次数、点赞数，点标题进入文章。
- **右侧**：登录后显示自己的头像和一句心情留言，下方是推荐位图片。

### 11.2 文章页

从上到下依次是：文章标题和副标题 → 发布人、发布时间、浏览次数、点赞数 → 正文 → 版权声明 → 点赞与收藏按钮 → 上一篇 / 下一篇 → 评论区 → 底部「返回」按钮。

> 自己发布的文章不显示点赞和收藏按钮。

### 11.3 互动规则

| 操作 | 需要登录吗 | 说明 |
| --- | --- | --- |
| 浏览文章、搜索 | 不需要 | 任何人都能看 |
| 点赞文章 | 需要 | 再点一次可取消点赞 |
| 收藏文章 | 需要 | 收藏列表在个人中心查看 |
| 给评论点赞 | 需要 | 再点一次可取消 |
| 发表评论 | 需要 | 提交后要等审核通过才显示 |
| 回复他人评论 | 需要 | 同样需要审核 |

### 11.4 个人中心

顶部导航里点自己的头像可进入个人中心，能看到：文章获赞数、评论获赞数、评论数、收藏文章数，以及「收藏的文章」「浏览历史」两个列表。

未登录时点进个人中心，会提示你先登录或注册。

## 12. 常见问题

**Q1：忘记后台密码了怎么办？**
在登录页点「忘记密码？」，用注册邮箱收验证码即可重置。

**Q2：注册时收不到邮箱验证码？**
① 确认邮箱地址没有输错；② 同一个邮箱 60 秒内只能获取一次，稍等再试；③ 连续输错验证码会被临时锁定约 10 分钟，稍后再试；④ 检查垃圾邮件文件夹；⑤ 如果系统尚未配置发信邮箱，验证码不会真正发出，请联系网站管理员。

**Q3：我的评论提交了但看不到？**
这是正常的：评论需要通过审核才会公开显示。到「评论管理」把「审核」筛成「待审核」，就能看到自己还排队的评论；等状态变成「已通过」，读者就能看到了。

**Q4：我的文章在前台找不到？**
按顺序检查：①「文章管理」列表里「显示」开关是否打开；② 是否在正确的页码（用搜索框按标题找最快）；③ 浏览器缓存——按 `Ctrl + F5` 强制刷新。

**Q5：为什么我的菜单比别人少？**
菜单按账号权限显示，你只会看到自己用得上的功能。「网站信息」「账号管理」「数据库管理」只对管理员开放。如果确实需要更多功能，联系网站管理员。

**Q6：提示密码不合格？**
密码要求：**8 位以上，并且同时包含大写字母、小写字母、数字、特殊字符**。设置密码时对照这个规则检查。

**Q7：上传图片失败？**
单个文件不超过 **5MB**；「封面」和「头像」需要图片格式（jpg / png / gif）。超限或格式不对都会失败，换一张再试。

**Q8：不小心点了「清理HTML」，内容变纯文字了怎么办？**
这个操作**无法撤销**。图片、链接、表格、列表结构都会丢失，只能重新排版。所以使用前请先保存一次，或改用「清除格式」（它只去文字样式，保留结构）。

**Q9：删掉的评论/文章/数据能恢复吗？**
不能。删除是彻底删除，操作前请确认；数据库管理里的删除与执行 SQL 同样如此。

**Q10：顶部铃铛有小红点是什么意思？**
表示有未读的回复消息。点一下铃铛会跳到「回复管理」，同时小红点消失。

**Q11：修改昵称提示不能改？**
昵称一年只能修改一次，间隔未满时无法提交。

## 13. 名词小词典

| 名词 | 意思 |
| --- | --- |
| **前台** | 读者浏览的网站（首页、文章页、关于我） |
| **后台** | 你登录后管理内容的界面（写文章、看评论的地方） |
| **排序** | 决定列表先后顺序的数字，越小越靠前 |
| **显示（开关）** | 是否让前台看到这条内容。关掉等于「暂存 / 下架」，内容不会丢 |
| **推荐（开关）** | 让文章有资格进入首页「推荐好文」位，仅管理员可设置 |
| **待审核** | 内容已提交，但还没公开显示，等管理员放行 |
| **已通过** | 审核完成，读者可以看到 |
| **摘要** | 文章的简短介绍，显示在列表里 |
| **封面** | 代表文章的那张图 |
| **富文本** | 正文的一种写法：所见即所得，直接排版 |
| **源码模式** | 查看 / 编辑正文的网页代码或纯文本语法，一般用不到 |
| **回复** | 针对某一条评论的再次回应 |
| **昵称** | 你在前台显示的名字（和登录用的账号名不是一回事，一年一改） |
| **ICP 备案** | 网站在有关部门登记的备案号，显示在页脚 |
| **超级管理员** | 拥有全部权限（含数据库管理）的账号 |
